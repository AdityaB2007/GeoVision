# GeoVision

**GeoVision** is a computer vision project focused on classifying satellite imagery into different land-use and land-cover categories.

The project explores image preprocessing, convolutional neural networks, transfer learning, and model evaluation to investigate how effectively machine learning can recognize geographic environments from satellite imagery.

## Goals

- Explore and preprocess satellite imagery
- Establish a baseline classification model
- Build and evaluate a CNN
- Experiment with transfer learning
- Analyze model performance and classification errors

## Technologies

- PyTorch
- NumPy, Pandas, Matplotlib, Seaborn, and Scikit-Learn
